# Markdown negotiation Worker

GitHub Pages serves the same bytes for every `Accept` header, so `Accept: text/markdown` and
`Vary: Accept` need an edge layer. `markdown-negotiation.mjs` is that layer (Cloudflare Workers).

| Request | Response |
|---|---|
| `Accept: text/markdown` on a page | 200, `Content-Type: text/markdown`, `Vary: Accept`, body from the page's `.md` twin |
| `Accept: text/html`, `*/*`, browsers | the normal HTML, with `Vary: Accept` added |
| Missing page + `Accept: text/markdown` | **404** with a Markdown error body linking to the homepage, `llms.txt` and the sitemap |

Markdown twins: `/index.md` (hand-written), `/about/index.md`, `/contact/index.md`, `/privacy/index.md`
(generated by `npm run build:md`; run it after editing those HTML pages, `npm test` fails if they are stale).

## Deploy (needs your Cloudflare account)

1. Put `fralencrm.in` on Cloudflare (change the nameservers at GoDaddy to the two Cloudflare gives you),
   keep the existing DNS records, set them to **Proxied**, and set SSL/TLS mode to **Full**.
2. `npm install -g wrangler && wrangler login`
3. `wrangler deploy` (routes for `www.fralencrm.in/*` and `fralencrm.in/*` are in `wrangler.toml`).
4. Verify:
   ```
   curl -sS -L -i -H 'Accept: text/markdown' https://www.fralencrm.in/
   curl -sS -L -i -H 'Accept: text/html'     https://www.fralencrm.in/
   curl -sS -L -i -H 'Accept: text/markdown' https://www.fralencrm.in/does-not-exist
   ```
   Expect Markdown + `Vary: Accept`, HTML, and a final `404` with `Content-Type: text/markdown`.

Tests: `npm test` (no dependencies, Node 20+).
